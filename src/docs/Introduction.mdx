# Nova UI

Доступная библиотека React-компонентов с дизайн-токенами, светлой и тёмной темой и полной поддержкой клавиатуры.

## Принципы

- **Доступность — по умолчанию, а не опционально.** Каждый интерактивный компонент следует паттернам [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/), каждый покрыт тестом axe, а контраст цветов в обеих темах проверяется автотестом.
- **Платформа прежде всего.** Где браузер уже умеет — используем его: нативные `<input type="checkbox">`, радиокнопки в `<fieldset>`, `<dialog>` с ловушкой фокуса и Esc из коробки.
- **Один API состояния.** Любой компонент со значением работает и управляемо (`value` + `onValueChange`), и неуправляемо (`defaultValue`) — как обычные инпуты.
- **Токены — единственный источник правды.** Цвета, отступы и радиусы описаны в `tokens.ts`; CSS-переменные генерируются из него, тест следит, чтобы они не разошлись.
- **Без зависимостей в рантайме.** Только React (как peer dependency). Вся библиотека — около 8 КБ JS и 5 КБ CSS в gzip.

## Установка

```bash
npm install @qwertyzxas/nova-ui
```

```tsx
import '@qwertyzxas/nova-ui/styles.css';
import { Button, TextField } from '@qwertyzxas/nova-ui';

export function SignUp() {
  return (
    <form>
      <TextField label="Email" type="email" required />
      <Button type="submit">Создать аккаунт</Button>
    </form>
  );
}
```

## Темы

Светлая тема включена по умолчанию, тёмная подхватывается из настроек системы. Чтобы выбрать тему явно, задайте атрибут на любом контейнере:

```html
<html data-nova-theme="dark">
```

Переключатель темы в панели инструментов Storybook сверху делает то же самое.

## Клавиатура

| Компонент | Клавиши |
| --- | --- |
| Select | ↑ ↓ Home End — навигация, Enter / Пробел / Tab — выбор, Esc — закрыть, буквы — поиск |
| Tabs | ← → (↑ ↓ для вертикальных) Home End — переключение вкладок |
| Dialog | Esc — закрыть, Tab остаётся внутри окна |
| Tooltip | появляется при фокусе с клавиатуры, Esc — скрыть |
| Switch, Checkbox | Пробел (Switch — ещё и Enter) |
